# Support

## How to Get Help

- Use GitHub Issues for bugs, incorrect guidance, missing scenarios, and concrete feature requests.
- Open a draft pull request when you already have a proposed change and want feedback on direction.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before starting substantial work.

## Not for Public Issues

- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)
- Sensitive repository or account details
- Private customer or client data

## What to Include

- The skill or workflow involved
- The prompt or task shape that triggered the problem
- Relevant file paths, commands, or references
- Expected behavior versus actual behavior
