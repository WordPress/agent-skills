# Benefit-Focused Readme Copy

Skill: wp-readme-optimizer

Plugin listing rewrites should focus on user benefits and trust signals, not keyword stuffing.

## Description and benefits stay concrete

**Given** a WordPress.org plugin readme rewrite
**When** the skill drafts the short description and key sections
**Then** it should emphasize who the plugin is for, what it solves, and why it is trustworthy

### Examples

Pass:
```text
Secure admin actions in custom WordPress plugins with reusable nonce and capability patterns, practical examples, and clear integration guidance.
```

Fail:
```text
Best WordPress plugin security nonce capability secure secure optimize boost rank #1 plugin.
```
This reads like keyword stuffing and does not explain the actual value to users.
