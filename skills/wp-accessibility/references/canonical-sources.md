# Canonical Sources for WordPress Accessibility

## Primary references

- **WP Accessibility Knowledge Base** — https://wpaccessibility.org/
  Community-maintained documentation covering content, design, code, forms, themes, and testing.
  Topics: https://wpaccessibility.org/docs/topics/
  Testing: https://wpaccessibility.org/docs/testing/
  WordPress-specific: https://wpaccessibility.org/docs/wp-a11y/

- **WordPress Accessibility Coding Standards** — https://developer.wordpress.org/coding-standards/wordpress-coding-standards/accessibility/
  Official standard: WCAG 2.2 AA + ATAG 2.0. Normative references: W3C WCAG 2.2, W3C ATAG 2.0, W3C WAI-ARIA 1.1.

## WordPress-specific APIs

- **@wordpress/a11y (wp.a11y.speak)** — https://developer.wordpress.org/block-editor/reference-guides/packages/packages-a11y/
  Dynamic content announcements via ARIA live regions.
