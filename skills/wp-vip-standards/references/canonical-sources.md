# Canonical Sources for WordPress VIP Standards

## Primary references

- **VIP Coding Standards (PHPCS)** — https://github.com/Automattic/VIP-Coding-Standards
  PHPCS rulesets: `WordPress-VIP-Go` (current) and `WordPressVIPMinimum` (legacy).

- **VIP Code Review documentation** — https://docs.wpvip.com/technical-references/code-review/
  What the VIP Code Analysis Bot checks and how violations are classified.

- **VIP Code Quality and Best Practices** — https://docs.wpvip.com/technical-references/code-quality-and-best-practices/
  Query optimization, caching requirements, banned patterns.

- **VIP Go documentation** — https://docs.wpvip.com/
  Platform constraints, deployment, file system, caching architecture.

## Baseline (prerequisite)

- **wp-secure-code skill** — WordPress Security API, WPCS security sniffs, OWASP patterns.
  VIP standards build on top of these. Always apply wp-secure-code first.
